# Graft

A programming language in design. Nothing works yet, and nothing is decided until it is logged in
[`DECISIONS.md`](DECISIONS.md).

> Graft is being designed, so please don't expect stability: anything may change or be removed, and it comes with
> **no warranty**. Only this repository speaks for Graft.

## Where things are

- [`design/pitch.md`](design/pitch.md): three directions for what Graft is, and the first decisions to make.
- [`DECISIONS.md`](DECISIONS.md): what the owner has decided, and when.
