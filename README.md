# Void

> **Void is abandoned (2026-11-01).** It was designed for one day and never implemented. This repository is kept as
> it was left.

A programming language in design: C syntax with a garbage collector, basically. It was called Graft until
2026-11-01. Nothing works yet, and nothing is decided until it is logged in [`DECISIONS.md`](DECISIONS.md).

> Void is being designed, so please don't expect stability: anything may change or be removed, and it comes with
> **no warranty**. Only this repository speaks for Void.

## Where things are

- [`DECISIONS.md`](DECISIONS.md): what the owner has decided, and when.
- [`design/samples.md`](design/samples.md): programs the owner wrote to show what Void looks like.
- [`design/most-void.md`](design/most-void.md): the most void Void program.
- [`design/pitch.md`](design/pitch.md): the first pitch, written while the language was Graft. Not taken.
